# Эмулятор командной строки (Вариант 6)

## Описание
Эмулятор оболочки ОС с поддержкой виртуальной файловой системы (VFS). 
Реализованы Этапы 1, 2 и 3.

## Реализованный функционал
- **Этап 1 (REPL):** Интерактивный цикл, приглашение вида `user@host:path$`, парсер аргументов, заглушки `ls` и `cd`, команда `exit`.
- **Этап 2 (Конфигурация):** Поддержка параметров `--vfs` и `--script` (через `argparse`). Отладочный вывод параметров. Выполнение стартового скрипта с имитацией диалога.
- **Этап 3 (VFS):** Загрузка виртуальной файловой системы из CSV-файла в память. Обработка ошибок загрузки (файл не найден, неверный формат).

## Структура проекта
- `src/shell_emulator.py` — основной код эмулятора.
- `src/vfs.py` — логика виртуальной файловой системы.
- `run.sh` — скрипт запуска.
- `vfs_test.csv` — тестовая виртуальная файловая система (3 уровня вложенности).
- `test_script.txt` — тестовый стартовый скрипт.

## Запуск
```bash
# Интерактивный режим
./run.sh --vfs vfs_test.csv

# Режим выполнения скрипта
./run.sh --vfs vfs_test.csv --script test_script.txt
