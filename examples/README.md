# Три примера и сравнение со штатным npm

Проверка выполнена 12 ноября 2026 года. Реестр: https://registry.npmjs.org.
Штатный инструмент: официальный npm CLI 12.2.2.
Глубина анализа — 5 переходов, обычные dependencies.

| Корень | Вершин | Рёбер | Совпадение с npm ls |
|---|---|---|---|
| is-odd@3.0.1 | 2 | 1 | версии и все связи совпадают |
| is-even@1.0.0 | 5 | 4 | версии и все связи совпадают |
| is-number@7.0.0 | 1 | 0 | совпадает, отдельная вершина |

Для каждого пакета сохранены описание Graphviz (*.dot) и штатное дерево
(*.npm-tree.txt). comparison.json фиксирует результаты сравнения.
Бинарные изображения не добавлены: вариант №6 требует вывод описания графа.

## Воспроизведение визуализатора

Из корня репозитория:

```sh
./run.sh --package is-odd --version 3.0.1 --depth 5 --dot-only
./run.sh --package is-even --version 1.0.0 --depth 5 --dot-only
./run.sh --package is-number --version 7.0.0 --depth 5 --dot-only
```

Пример is-even:

```text
is-even@1.0.0
└── is-odd@0.1.2
    └── is-number@3.0.0
        └── kind-of@3.2.2
            └── is-buffer@1.1.6
```

Граф совпадает с соответствующим *.dot. Для изображения можно передать
DOT отдельно установленному Graphviz: dot -Tsvg examples/is-even.dot.
В реализации получения зависимостей Graphviz и npm не участвуют.

## Воспроизведение штатного сравнения

Создать отдельную временную папку и package.json:

```json
{
  "name": "comparison-demo",
  "version": "1.0.0",
  "private": true,
  "dependencies": {"is-even": "1.0.0"}
}
```

В ней выполнить:

```sh
npm install --package-lock-only --ignore-scripts --no-audit --no-fund
npm ls --all --package-lock-only
npm ls --all --package-lock-only --json
```

Повторить для is-odd@3.0.1 и is-number@7.0.0. Сравнивать пары имя/версия
и связи между ними, а не формат отступов. В проверке JSON npm ls преобразован
в список смежности и сопоставлен с результатом программы.
Пакеты не исполняются, файлы установки не добавляются в этот репозиторий.

## Расхождения и границы сравнения

Для этих трёх примеров расхождений в вершинах, версиях и связях нет.
DOT — граф, а npm ls — дерево, поэтому текстовое оформление различается.

Для других проектов возможны различия: здесь анализируются обычные registry
зависимости, без peer/optional, lock-файла, workspace и npm overrides.
Одинаковая пара имя/версия объединяется в вершину, хотя npm может показать
её в нескольких местах дерева. При ограничении глубины более дальние узлы
не исследуются. Эти ограничения не скрываются и не заменяются latest.
